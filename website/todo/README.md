# What's left on the website

The website is built. What's left waits on something else happening first. Each file here is one of those "somethings",
in the order we expect them.

| When | File |
|---|---|
| Now, with the software | [after-software.md](after-software.md): what the website owes because of the software |
| After one meeting | [after-meeting.md](after-meeting.md): address, grievance officer, city for disputes |
| When you're in the mood to design | [design.md](design.md): logo, favicon, link preview, blog cover |
| After the sole proprietorship is registered | [after-proprietorship.md](after-proprietorship.md): card payments, GST |
| After the private limited company is registered | [after-pvt-ltd.md](after-pvt-ltd.md) |
| Launch day, when you say | [launch.md](launch.md): the domain, Google, visitor numbers |

The plan, in order: October tests with real people (UPI, checked by hand) → software built → proprietorship registered
→ card payments → 50 users → about a month of selling → private limited.

**How to use these files.** When something is done, delete its line. When a file is empty, delete the file. Anything
already decided lives in the code (`site/src/consts.ts` holds every business detail and price), not here.
